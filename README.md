# کـاتـەکـە بـگـرە (Match The Time) ⏱️

یارییەکی زۆر شاز و بەچێژ بۆ ئەو کاتانەی لەگەڵ هاوڕێکانت کۆدەبنەوە! تاقیکردنەوەی ئەوەیە بزانن کێ مێشکی کاتژمێری باشترە. یارییەکە بە دیزاینێکی دارک مۆدی نایاب و دەنگی تایبەت (Beeps) دروستکراوە.

## مۆدەکانی یارییەکە 🎮

* **مۆدی ١: کاتی شاراوە**
  کاتەکە دیار نییە کە دەڕوات. لەگەڵ هاوڕێکانت کاتێک دیاری بکەن (بۆ نموونە ٥ چرکە)، سپەیس دابگرە بۆ دەستپێکردن، وە هەوڵبدە ڕێک لەسەر ٥ چرکەکە ڕایگریت!

* **مۆدی ٢: حەزەرکردن**
  کاتەکە دیارە کە دەڕوات. کەسێک با کاتەکە ڕابگرێت و ئەوانی تر دەبێ حەزەر بکەن (پێشبینی بکەن) کە کاتەکە لە چەند وەستاوە!

* **مۆدی ٣: شەڕە تیم**
  ئەم مۆدە باشترە بە ٢ ئامێر (لابتۆپ) بکرێت لە یەک کاتدا بۆ دوو تیم. دەبێت هەر تیمێک بگەنە ئەو کاتەی کە لە نێوان خۆیاندە دیاریان کردووە (بۆ نموونە ٢٠ چرکە).
  * **SPACE** دابگرە بۆ دەستپێکردن و وەستاندن (کاتەکە کەڵەکە دەبێت).
  * **ENTER** دابگرە بۆ ئاشکراکردنی کاتی کۆتایی تیمەکە ئەگەر تەواو بوون یان تەسلیم بوون.
  * **BACKSPACE** بۆ سفرکردنەوە.
