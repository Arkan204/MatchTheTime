# کـاتـەکـە بـگـرە (Match The Time) ⏱️

[![Play Now](https://img.shields.io/badge/Play_Now_🎮-match--the--time.vercel.app-22c55e?style=for-the-badge)](https://match-the-time.vercel.app/)

**[👉 کلیک لێرە بکە بۆ یاریکردن](https://match-the-time.vercel.app/)**

یارییەکی زۆر شاز و بەچێژ بۆ ئەو کاتانەی لەگەڵ هاوڕێکانت کۆدەبنەوە! تاقیکردنەوەی ئەوەیە بزانن کێ مێشکی کاتژمێری باشترە. یارییەکە بە دیزاینێکی دارک مۆدی نایاب و دەنگی تایبەت (Beeps) دروستکراوە.

## مۆدەکانی یارییەکە 🎮

* **مۆدی ١: کاتی شاراوە**
  کاتەکە دیار نییە کە دەڕوات. لەگەڵ هاوڕێکانت کاتێک دیاری بکەن (بۆ نموونە ٥ چرکە)، سپەیس دابگرە بۆ دەستپێکردن، وە هەوڵبدە ڕێک لەسەر ٥ چرکەکە ڕایگریت!

* **مۆدی ٢: حەزەرکردن**
  کاتەکە دیارە کە دەڕوات. کەسێک با کاتەکە ڕابگرێت و ئەوانی تر دەبێ حەزەر بکەن (پێشبینی بکەن) کە کاتەکە لە چەند وەستاوە!

* **مۆدی ٣: شەڕە تیم**
  ئەم مۆدە باشترە بە ٢ ئامێر (لابتۆپ) بکرێت لە یەک کاتدا بۆ دوو تیم. دەبێت هەر تیمێک بگەنە ئەو کاتەی کە لە نێوان خۆیاندە دیاریان کردووە (بۆ نموونە ٢٠ چرکە).
  * **SPACE** دابگرە بۆ دەستپێکردن و وەستاندن (کاتەکە کەڵەکە دەبێت).
  * **ENTER** دابگرە بۆ ئاشکراکردنی کاتی کۆتایی تیمەکە ئەگەر تەواو بوون یان تەسلیم بوون.
  * **BACKSPACE** بۆ سفرکردنەوە.

* **مۆدی ٤: شەڕە تەقە (Duel)**
  ئەم مۆدە بۆ دوو یاریزانە لەسەر یەک ئامێر. یاریزانی ١ پەنجە لەسەر پیتی 'A' (یان لای چەپی شاشەی مۆبایل) دادەنێت و یاریزانی ٢ لەسەر 'L' (یان لای ڕاستی شاشە). پاشان چاوەڕێی ڕووناکی سەوز بکەن (کە کاتێکی هەڕەمەکییە لە ١ بۆ ٢٠ چرکە). هەرکەسێک زووتر پەنجەی لادا ئەو دەیباتەوە! ئەگەر زووتر لە ڕووناکییەکە پەنجەت لادا دەدۆڕێیت.

* **مۆدی ٥: کاتی شاراوەی دووانە (Dual Blind)**
  بۆ دوو یاریزانە، لەگەڵ هاوڕێکەت کاتێک دیاری بکەن. یاریزانی ١ دوگمەی 'A' دادەگرێت بۆ دەستپێکردن و وەستاندنی کاتە شاراوەکەی خۆی، یاریزانی ٢ دوگمەی 'L' بەکاردەهێنێت. هەرکەسە و بە جیا کاتەکە دەستپێدەکات و دەیوەستێنێت. پاشان SPACE دابگرن بۆ ئاشکراکردنی هەردوو کاتەکە بەیەکەوە و بزانن کێ براوەیە!
